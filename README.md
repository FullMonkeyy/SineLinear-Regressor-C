# SineLinear-Regressor-C++
Hi,here you will find the code to develop a Machine Learning linear regressor model with an approximated sine function which lead the algorithm not to forget the error during the training.

The program is completely coded in C language. Actually I wanted to show how also an low level programming language as C could be optimal for base machine learning programs.

Beside, you will find also an documentation which is written in italian (this just becouse I'm italian too) where i wrote about the algorithm it self and not the code.

#⚠️ DISCLAIMER ⚠️ About the methodology of this project

This algorithm was developed entirely from scratch when I was 17 years old, driven by pure curiosity and intuition, well before my university studies in calculus, linear algebra, and formal Machine Learning.Please note that this is an experimental and heuristic approach, not a standard implementation. It does not utilize traditional, mathematically optimal methods such as Ordinary Least Squares (OLS), matrix operations, or Gradient Descent.Instead, it relies on a custom $O(N^2)$ brute-force logic and a sine-wave-based "Magnitude" function to intuitively simulate error regularization, non-linear fitting, and loss penalization. While computationally heavy and mathematically unorthodox for real-world production, this project was my very first independent attempt to reverse-engineer the core concepts of optimization and algorithmic learning.It remains in my portfolio not as a production-ready ML model, but as a testament to my early passion for problem-solving and out-of-the-box thinking, which laid the groundwork for the rigorous academic methodologies I apply today.
